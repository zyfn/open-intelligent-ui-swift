# 0.1.1-rc.21

本次发布属于独立的 Swift Intelligent UI 原生工作区，保持仓库既有访问权限。它不发布公共 OpenUI fork、不变更 main，也不代表真机或全部组件状态验收。

## 内容与依赖修复

- 整合分支基于 132a7b4，包含 OpenUI Swift 集成、D1–D5 修复、POI/图片呈现及 d27b9021 的数字草稿反馈修复。
- Core Zod 从4.4.3升级并固定为4.6.6，修复 GHSA-mrhx-c7xc-m3w5。验证安装的版本、公共registry完整性、锁文件及重新生成的JavaScriptCore资源。
- 当前Core资源SHA256：339bd90f6b8d92c3bfb553955b81eea35fa3404ecd2b751ca7b378ff2b30dfbf。OpenUI/IMPORT.json继续保留首次导入的历史身份，不伪称升级后仍与原始导入字节一致。
- 新Zod压缩type union的导出形式，且JSON导入的record多了一层pipeline。现有authoring桥接保留record身份，统一的schema-emission转换仅保持旧有JSON Schema wire形态；不改验证规则、组件顺序、源码解析器或共享签名算法。原标准库资源及历史reader契约的严格比较仍启用。
- strict-compatibility.json只更新依赖升级后的oracle bundle指纹；解析/动作/查询/序列化预期逐字段相同，不重录行为基线。
- 补齐Functions生成工具的锁文件；安全CI检查所有五个打包生成器依赖图，仍以high为失败门槛，不隐藏较低级别提示。
- 清单导出和本地源码包统一为0.1.1-rc.21。Gallery中的Spacer调用按现有无参数契约修正；图像边缘测试使用固定已加载红图，原位置断言和透明失败态回归保持。

## 验证范围

发布证据随GitHub prerelease资产提供，包括所有原始命令、退出码和早期失败记录。本地macOS26.3.2、Xcode26.6、Swift6.3.3检查结果：

- 51项严格parser比较、5条官方动作轨迹、4个受控query快照、6个serializer回放。
- 全部61项历史reader的完整schema、有序签名、函数/动作对比。
- 两套原生库共764项Swift测试、102项语言ASan、3项Release fitting、26个Gallery固定程序全部通过。
- 标准库macOS示例、全部库的iOS16 Simulator目标和iOS Gallery编译。
- 公共npm registry的五个依赖图audit：没有high/critical；富文本及Functions图仍有low提示，未声明零漏洞。
- 生成器可复现性、布局/本地化及ownership检查。

GitHub Actions当前因账户账单/额度未启动，不能称CI通过；本地Apple工具链结果与CI状态分别记录。iOS编译不是iPhone运行，原有真实IME、完整VoiceOver、物理RTL指针和离屏截图差异等范围不由这次依赖更新关闭。
